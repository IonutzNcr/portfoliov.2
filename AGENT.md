# Project instructions

## Stack
- react: ^19.2.8,
- react-dom: ^19.2.8
- TypeScript
- CSS (file .css)

## Architecture
- Use the file architecture.md for guide-line
- Try to respect as much as possible the guide-line

## Rules
- Use a file architecture base on the given file: architecture.md
- Always produce code readable and maintainable by human
- Always document your choise of implementation and the techno you will add if necessary
- Always respect the design made by Stitch
- The components and layout produces should always be responsive
- Always use TypeScript.
- Never use `any`.
- Make always unit test for each functions you use
- Always follow best practice to have a clean code
- Make integration test
- API calls must go through src/services/.
- Run `npm test` before finishing a change.

## Naming conventions
- React components: PascalCase
- Functions: camelCase
- Constants: UPPER_SNAKE_CASE
